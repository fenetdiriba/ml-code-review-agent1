# 💬 ML Code Review Chat Assistant

## 🎯 How to Open the Chat Interface

### Method 1: Command Palette
1. **Open Command Palette**: `Cmd+Shift+P` (Mac) or `Ctrl+Shift+P` (Windows/Linux)
2. **Type**: "ML Code Review"
3. **Select**: "ML Code Review: Open Chat Assistant"

### Method 2: Extension Development Host
1. **Press F5** to launch extension development host
2. **Use Command Palette** as above
3. **Chat panel** will open in a new webview
